# M01-E01 — What is a material? A biologist's translation

## Episode role

This is the pilot episode for Module 1. Its job is not to teach all of materials science. Its job is to reframe what biologists already know — structure, function, adaptation, phenotype, tissue organisation — into the language of materials science.

## Working title

**English:** What is a material? A biologist's translation  
**Spanish:** ¿Qué es un material? Una traducción para biólogos

## Target length

35–40 minutes.

## Core message

A material is not just a substance. A material is matter organised across scales so that it performs a function under physical constraints.

For a biologist, this should feel familiar: structure–function thinking is already central to biology. Materials science formalises that intuition using processing, structure, properties, and performance.

## Learning goals

By the end of the episode, the viewer should be able to:

1. Explain why biological tissues can be analysed as materials.
2. Distinguish substance, structure, property, and performance.
3. Understand the processing–structure–properties–performance framework.
4. Recognise that biological function can be translated into measurable material performance.
5. See why materials science is useful for biomechanics, biomimetics, biomedical science, ecology, conservation, and evolutionary biology.

## Tone

- University-level but accessible to biology-trained viewers.
- No infantilising definitions.
- Start from biological competence, then translate.
- Use orchids and other biological materials as recurring anchors.

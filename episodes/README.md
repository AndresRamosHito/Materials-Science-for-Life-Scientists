# Episodes

This folder will hold episode plans, scripts, slide notes, and shot lists.

## Episode planning checklist

For each episode, create a folder:

```text
episodes/
  M01-E01/
    script_en.md
    script_es.md
    shot_list.md
    asset_needs.md
    slide_notes.md
```

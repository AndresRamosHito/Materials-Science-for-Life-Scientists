# AI prompt library

Reusable prompts for figures, schematics, backgrounds, transitions, and storyboard drafts.

## Prompt rules

1. Ask for no embedded text.
2. Ask for empty space where labels will be added later.
3. Specify scientific role: schematic, metaphor, background, or storyboard.
4. Avoid requesting a literal scientific structure unless you will verify it manually.
5. Save the final prompt in the asset register.

## Generic scientific schematic prompt

```text
Create a clean scientific illustration on a black background, no text, no labels.
Subject: [concept].
Show: [main visual elements].
Style: modern educational science diagram, high contrast, minimal, readable at small size.
Leave empty space for labels.
Avoid cartoon style. Avoid unrealistic anatomy. Avoid decorative clutter.
```

## Hierarchy diagram prompt

```text
Create a text-free scientific hierarchy diagram on a black background.
Show four nested scales: organism-level structure, tissue, microstructure, molecular architecture.
Use clean circular or rectangular panels connected by subtle arrows.
Modern educational science style, high contrast, minimal, suitable for university lecture slides.
No labels, no words, no numbers.
```

## Visual metaphor prompt

```text
Create a text-free conceptual visual metaphor for [concept].
The image should communicate [intuition] without presenting itself as real data or microscopy.
Black background, minimal high-contrast scientific style, no labels, no text.
Leave space for slide labels.
```

## Stock/AI transition prompt

```text
Create a short abstract science transition visual, no text.
Theme: [module concept].
Visual elements: [fibres/networks/gels/cracks/cells/material layers].
Style: restrained, cinematic, black background, suitable as a 3-second transition in an educational lecture video.
```
